# my-tools — note 記事の作業机

完成したnote記事のタイトルと本文を保存・編集・コピーする、個人用の日本語Webアプリです。外部依存、ログイン、ビルドは不要です。

## パソコンで開く

1. GitHubのこのリポジトリで **Code → Download ZIP** を選びます。
2. ダウンロードしたZIPを右クリックし、**すべて展開** します。
3. 展開したフォルダの **index.html** をダブルクリックし、ChromeやEdgeで開きます。
4. タイトルと本文を入力して **記事を保存** を押します。
5. 保存した記事は左側の一覧から開いて編集できます。編集後も保存を押してください。
6. **タイトルをコピー**、**本文をコピー** でコピーし、noteの記事編集画面に貼り付けます。

コピーがブラウザに拒否されたときは、選択された文章を Ctrl+C（Macは⌘+C）でコピーしてください。

## 保存について

- 保存先は使用中のブラウザのlocalStorageです。ブラウザを閉じても残ります。
- 同じブラウザで、同じ場所のindex.htmlを開いて使用してください。ファイルを移動すると別の保存場所になる場合があります。
- file://での保存挙動はブラウザによって異なります。通常モードのChromeまたはEdgeで、まず試しの記事を保存して開き直してください。
- 別端末・別ブラウザとの同期はありません。シークレットモードやブラウザのデータ削除では消えることがあります。
- **バックアップを書き出す** でJSONファイルに保存できます。**バックアップを読み込む** は既存の記事を残して追加します。
- 未保存の編集内容はバックアップに含まれません。
- 保存失敗時は成功扱いにせず、入力内容を残して案内を表示します。壊れた保存データの上書きも防ぎます。

## 開発環境で開く

Python 3がある場合、リポジトリのフォルダで次を実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

同じパソコンのブラウザで http://localhost:8000 を開きます。停止はCtrl+Cです。file://版とは別の保存先になります。クラウド開発環境のlocalhostは自分のパソコンとは別なので、手元では上のZIP方式を使ってください。

## 機能

- 記事の新規作成・保存・一覧・検索・編集・削除
- タイトルと本文の個別コピー、本文の文字数
- 未保存の変更を破棄するときの確認
- JSONバックアップの書き出しと追加読み込み
- Ctrl/⌘+Sで保存
- スマートフォン幅でも使えるレイアウト

noteへの自動投稿・AI記事生成・認証情報の入力機能はありません。記事をGitHubや外部サーバーへ送る処理もありません。
