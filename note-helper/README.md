# note 下書き入力ヘルパー（試作）

スクリーンショットで確認したnoteのタイトルtextareaとProseMirror本文欄へ、ユーザーのクリックで入力するManifest V3拡張です。実際のnoteアカウントでの動作は未検証です。最初は空のテスト記事で試してください。

## Braveに追加する

1. リポジトリの最新ZIPをダウンロードし、展開します。
2. Braveのアドレス欄に `brave://extensions` と入力してEnter。
3. 右上の「デベロッパーモード」をオン。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開した `my-tools-main` の中の **note-helperフォルダ** を選びます。ZIPそのものは選ばないでください。
6. ツールバーの拡張機能メニューから「note 下書き入力ヘルパー」を開けます。

## 使う

1. 最新の作業机（index.html）で記事を開き、「note用データをコピー」を押します。
2. noteで新しい空の記事を開きます。
3. 拡張機能を開き、記事データ欄にCtrl+Vで貼り付けます。
4. 「開いているnoteに入力する」を押します。最初は下書き保存のチェックを外したまま試します。
5. タイトル、本文、改行、文字数を確認し、noteの「下書き保存」を押します。いったん閉じて下書きを開き直し、文章が残るか確認してください。
6. 入力が問題なければ、以後「入力後に下書き保存も押す」を選べます。ただしボタンのクリックとサーバー保存の完了は別なので、保存結果はnoteで確認してください。

## 範囲と仕様

- 下書き入力ボタンは公開を行いません。別の時間指定公開機能は下記を参照してください。
- 権限はactiveTabとscriptingのみ。ユーザーが機能を開いたタブに限って使います。外部への通信、Cookie取得、ログイン情報の保管は行いません。
- 記事に既存の本文や画像があれば停止します。
- タイトルはnative setterとinput/changeイベント、本文はブラウザのinsertText操作で入力します。ProseMirrorの内部状態への反映は実環境で確認が必要です。
- スクリーンショットから確認したセレクターに基づく試作です。noteのUI変更・ブラウザ差で動かない場合があります。
- 途中で止まった場合は自動保存を押さず、画面を確認するよう案内します。note側の自動保存が存在する場合、それを停止するものではありません。
- 本文はプレーンテキスト。画像・見出し書式・太字などは別途noteで設定してください。
- 正式なnote連携APIを使う拡張ではありません。


## 0.2.0：公開ボタンの時間指定（試作）

noteの公式予約投稿ではなく、開いたタブで待機し、指定時刻に「投稿する」を1回クリックします。PCを起動してBraveと公開設定タブを開いたままにしてください。小窓は閉じても構いません。

### 更新

最新ZIPを展開した新しいnote-helperフォルダを「パッケージ化されていない拡張機能を読み込む」で読み込みます。古い拡張が残る場合は古い方を削除し、新しい0.2.0を使用してください。作業机の記事のブラウザ保存は拡張削除とは別です。更新前に稼働中のタイマーは取り消してください。

### 操作

1. 公開してよいテスト記事をnoteに下書き保存します。
2. 「公開に進む」を押し、記事タイプ・ハッシュタグ・その他の公開設定を確認します。
3. 公開設定画面のタブでヘルパーを開き、「時間指定で公開」までスクロールします。
4. まず2〜3分後の日時を入れます。日時はPCのタイムゾーンに従います。
5. 「この記事と公開設定を確認しました。指定時刻の公開を許可します」にチェックし、公開タイマーを開始します。
6. noteの画面右下に待機表示が出ます。PCとタブを開いたまま、設定を変更せず待ちます。
7. 時間になると投稿ボタンを1回押します。クリック成功とサーバーでの公開完了は別なので、noteの画面と記事URLで公開結果を確認してください。

### 制限

- スリープ、PCの停止、ブラウザ終了、タブを閉じる、再読み込みでは動きません。再読み込み後にタイマーは復元されません。
- ページ移動、公開設定画面のテキストやフォーム値の変化を検出したら停止します。note側の動的な画面更新でも停止する場合があります。その際は設定を確認して再設定してください。
- スリープ等で予定時刻から2分を超えて遅れた場合、勝手に後から投稿しません。
- ブラウザの省メモリ機能によるタブ破棄、バックグラウンドタイマー制限で実行が遅れたり停止したりします。最初のテストは対象タブを前面で開いてください。
- 取り消しは画面右下のボタン、または同じタブのヘルパーから可能です。すでにクリック済みの公開は取り消せません。
- 投稿ボタンを押した後に追加の確認が出ても自動で進まず、再クリックもしません。
- タイマーはnoteページ内で実行されます。厳密な時刻保証、無人の長期運用、サーバー側の予約機能ではありません。
- 実際のnoteでの時間指定公開は未検証です。入力と下書き保存はユーザーの環境で動作確認済みです。
