# note 下書き入力ヘルパー（試作）

スクリーンショットで確認したnoteのタイトルtextareaとProseMirror本文欄へ、ユーザーのクリックで入力するManifest V3拡張です。実際のnoteアカウントでの動作は未検証です。最初は空のテスト記事で試してください。

## Braveに追加する

1. リポジトリの最新ZIPをダウンロードし、展開します。
2. Braveのアドレス欄に `brave://extensions` と入力してEnter。
3. 右上の「デベロッパーモード」をオン。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 展開した `my-tools-main` の中の **note-helperフォルダ** を選びます。ZIPそのものは選ばないでください。
6. ツールバーの拡張機能メニューから「note 下書き入力ヘルパー」を開けます。

## 使う

1. 最新の作業机（index.html）で記事を開き、「note用データをコピー」を押します。
2. noteで新しい空の記事を開きます。
3. 拡張機能を開き、記事データ欄にCtrl+Vで貼り付けます。
4. 「開いているnoteに入力する」を押します。最初は下書き保存のチェックを外したまま試します。
5. タイトル、本文、改行、文字数を確認し、noteの「下書き保存」を押します。いったん閉じて下書きを開き直し、文章が残るか確認してください。
6. 入力が問題なければ、以後「入力後に下書き保存も押す」を選べます。ただしボタンのクリックとサーバー保存の完了は別なので、保存結果はnoteで確認してください。

## 範囲と仕様

- 公開や予約投稿は行いません。タイマーで無人実行する機能もありません。
- 権限はactiveTabとscriptingのみ。ユーザーが機能を開いたタブに限って使います。外部への通信、Cookie取得、ログイン情報の保管は行いません。
- 記事に既存の本文や画像があれば停止します。
- タイトルはnative setterとinput/changeイベント、本文はブラウザのinsertText操作で入力します。ProseMirrorの内部状態への反映は実環境で確認が必要です。
- スクリーンショットから確認したセレクターに基づく試作です。noteのUI変更・ブラウザ差で動かない場合があります。
- 途中で止まった場合は自動保存を押さず、画面を確認するよう案内します。note側の自動保存が存在する場合、それを停止するものではありません。
- 本文はプレーンテキスト。画像・見出し書式・太字などは別途noteで設定してください。
- 正式なnote連携APIを使う拡張ではありません。
